# 👽🛸 Uber with an Alien

A just-for-fun parody rideshare site where your driver is an alien in a UFO. Not affiliated with Uber.

## Features
- Warp-speed starfield background
- Hovering UFO with a tractor beam abducting a cow
- Glitchy neon typography
- **BOOK RIDE** button → pick a planet, summon a saucer, get a random alien driver
- Click anywhere for space-junk confetti

## Run it
Just open `index.html` in a browser. No build step.

## Put it online with GitHub Pages
1. Create a new repo on GitHub and upload `index.html` and this `README.md`.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. In a minute or two your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Add your own Alien HR photo
Upload a photo named `hr.jpg` next to `index.html`. The **Call Alien HR** screen will show it.
If there's no `hr.jpg`, the cartoon alien boss shows instead.
